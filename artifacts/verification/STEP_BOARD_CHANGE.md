# Разборы в оформлении готовой доски

По запросу пользователя вместо MP4 применяется тот же React-компонент зелёной доски, что и для готовых заданий 1–19. Существующая разметка и стили вынесены из `Videos.tsx` в общий `SolutionBoard.tsx`.

Свои задачи открываются отдельным экраном: условие, доска с появляющимися записями и пояснением Звёздочки, список шагов справа, начало/назад/вперёд/пауза/скорость, «Понял», «Не понял» и переход к проверке. «Не понял» передаёт условие и текущий шаг помощнику. Ссылку на свой разбор можно открыть напрямую; история сохраняется в прежней таблице.

Сервер теперь генерирует JSON: название, шаги с короткими строками для доски и пояснением для каждого шага. Сборка MP4, Chromium, FFmpeg и edge-tts в этом процессе не используются; соответствующие зависимости убраны из Docker-сборки. Озвучка, если включена в профиле, использует прежний голос браузера.

Старые сохранённые решения тоже отображаются через новую доску: строки извлекаются из сохранённых SVG-групп, пояснения — из наррации. Существующие медиафайлы не удалялись, но видеоплеера, iframe и скачивания MP4/MP3 в интерфейсе разборов нет.

Проверено на запущенном проекте:

- Production-сборка TypeScript/Vite и проверка пробелов Git проходят.
- Предыдущий сохранённый разбор квадратного уравнения возвращает 7 шагов с записями для доски.
- Новый разбор задачи о вписанной окружности подготовлен моделью за 4 шага, ответ 52; для него не создаются MP4/MP3 и ссылки на них отсутствуют.
- В браузере открывается зелёная доска, работают пауза, выбор произвольного шага, завершение и возврат к списку.
- В DOM своего разбора отсутствуют video и iframe.
- Готовое задание №1 после выделения общего компонента отображается с прежними тремя шагами и кнопками.
