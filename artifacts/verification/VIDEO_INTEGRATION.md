# Генератор видеоразборов — интеграция

> Обновлено по последующему пожеланию: видео заменено пошаговой зелёной доской из готовых разборов. Текущая реализация описана в `STEP_BOARD_CHANGE.md`; ниже — отчёт о предыдущем варианте.

В разделе «Разборы» добавлен блок «Разобрать свою задачу». Готовые типовые разборы №1–19 сохранены.

В основу взяты `llm.py`, `engine.py`, `tts.py`, `render.py` из предоставленного архива `AiEGEVideoGenerator-main.zip`. Отдельное приложение с SQLite и чатами не запускалось: история интегрирована в PostgreSQL текущего проекта через таблицу `generated_videos`, файлы — в существующий постоянный uploads volume (`/app/uploads/videos`).

Путь обработки: текст условия → модель → SVG-доска и наррация → озвучка каждого шага через edge-tts → снимки Chromium → FFmpeg → MP4 и MP3. На странице отображаются этап подготовки, сохранённая история, видеоплеер, скачивание MP4/MP3 и интерактивная доска. Доска доступна сразу после подготовки решения, до окончания сборки видео.

Сервер использует настройки модели текущего `.env`. Генерируется одно видео одновременно; у пользователя может быть одно незавершённое задание, общая очередь ограничена восемью. После сбоя доступен повтор. Если решение уже сохранено, повтор не запрашивает его у модели заново. При перезапуске незавершённые задания отмечаются как прерванные с возможностью повтора.

Меры изоляции: API истории проверяет владельца; медиа доступны по ограниченному подписанному токену конкретного видео. Пользовательский JWT не передаётся в URL. Модель не задаёт исполняемый плеер: из её HTML извлекаются только разрешённые SVG-примитивы и атрибуты, оболочка и JavaScript собираются приложением. Доска показывается в sandbox iframe с CSP. Рендерер не допускает сетевых запросов страницы.

Проверено 17 ноября 2026:

- TypeScript/Vite production-сборка проходит, `git diff --check` проходит.
- Реальная генерация: квадратное уравнение `x² − 5x + 6 = 0`, 7 шагов, корни 2 и 3, разложение и проверка.
- Полный процесс завершился: MP4 **92,967 секунды**, H.264 и звуковая дорожка AAC; отдельный MP3 получен из той же озвучки.
- Проверены создание (202), короткое/пустое условие (422), повторная отправка во время подготовки (409), запрет повторной генерации готового видео через retry (409).
- Другой аккаунт не видит метаданные/историю и не может повторить чужую работу (404). Без авторизации история закрыта (403).
- Недействительный медиатокен отклонён (401), выдача MP4 с Range возвращает 206, ссылки стабильны при опросе статуса.
- SVG с `<script>`, обработчиком события, внешним изображением и foreignObject очищается; наррация с апострофом и `</script>` безопасно кодируется.
- В браузере: статус подготовки, открытие доски, возвращение из типового №13 к своей истории, воспроизведение готового MP4 (`paused=false`, `readyState=4`), кнопки скачивания, восстановление истории после обновления страницы.

Сценарий сквозной проверки — `check_videos.py` (запускается внутри backend-контейнера). Снимок результата — `videos-ui.jpg`.

Ограничения: математическая правильность произвольных задач не гарантируется одним успешным примером. Генерация и нейронная озвучка требуют доступа к настроенному LLM-серверу и сервису edge-tts. Отказ внешнего сервиса отображается как ошибка с повтором; готовая доска сохраняется. Новый сценарий принимает текст задачи, загрузка фото условия для генератора не добавлена.
