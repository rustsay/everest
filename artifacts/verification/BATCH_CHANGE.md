# Общая загрузка фотографий

Основной режим проверки — «Все фото сразу». Прежняя загрузка JPG/PNG/PDF отдельно в карточку задания сохранена в «По заданиям вручную».

В общей загрузке: до 30 JPG/PNG/WebP, 15 МБ на фото и 80 МБ на работу. Изображения декодируются, ориентируются по EXIF, приводятся к JPEG и сохраняются в закрытом inbox сессии. Модель предлагает номера 13–19 для каждого листа; неизвестные номера требуют ручного выбора. Один лист может относиться к нескольким заданиям. Пользователь проверяет выбор, меняет порядок/убирает лишнее и подтверждает запуск. Распределение сохраняется на сервере; после ручных изменений нужно нажать «Сохранить распределение» или «Проверить работу».

Фотографии для каждого задания передаются в существующую цепочку OCR → три эксперта → судья. На листе с несколькими заданиями эксперты получают указание проверять только нужный номер. Выполняются до двух проверок одновременно. Максимум изображений, передаваемых экспертам, увеличен с 4 до 30. Добавлены постоянный Docker volume для OCR-моделей и блокировка инициализации/вызовов общего PaddleOCR predictor: сквозной тест выявил гонку при одновременной загрузке моделей.

Фото, превью, сохранение распределения и запуск проверки защищены проверкой владельца сессии. Уже отправленные фото нельзя удалить/перераспределить. Добавление новых фото к отправленному заданию запускает проверку с прежними и новыми листами. Отдельная кнопка повторяет только задания со статусом ошибки. Результаты обновляются через WebSocket и резервный опрос API.

- В браузере: массовый выбор двух файлов, автоматическое распределение, ручная перестановка, сохранение, переключение на старые карточки и обратно, запуск проверки, получение двух оценок.

Сквозные сценарии: `check_batch.py`. Снимок интерфейса: `batch-upload-ui.jpg`.

Распределение на реальных рукописных работах может ошибаться — поэтому перед проверкой всегда доступна ручная коррекция. Листы без определённого номера не отправляются молча в случайное задание. Общая загрузка PDF/архивов в этот режим не добавлялась.
